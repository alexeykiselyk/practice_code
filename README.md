# **Practice code** in lead-up to PhD

Simple practice code in C and Fortran. 

Two main files used in C coding:

  `own_newton_method.c` - displays code which applies Newton's method to a polynomial of order 2.
  
  `met_has.c` - applies the Metropolis-Hastings algorithm to a 2D square grid of a variable number of points. Each point is either on (1) or off (0). Found in Metropolis Hastings folder.

The file 'Fortran' contains files showcasing basic practice, getting used to syntax, using data types, arrays, floating point precision, workflows and code structure.
